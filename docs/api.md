# 系统 API 接口技术手册

## 1. 登录模块 (LoginController)

### 1.1 用户登录
- **接口描述**：用户通过用户名和密码进行登录验证，成功则返回访问令牌（Token）。
- **请求路径**：`/login`
- **请求方法**：`POST`
- **请求头**：`Content-Type: application/json`

#### 请求参数
| 参数名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| username | String | 是 | 用户名 |
| password | String | 是 | 密码 |

#### 返回参数
| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| code | Integer | 状态码（200为成功） |
| message | String | 提示信息 |
| data | String | 登录成功后的 Token 字符串 |

#### 错误码定义
| 错误码 | 说明 | 处理建议 |
| :--- | :--- | :--- |
| 401 | 密码错误或用户不存在 | 请检查用户名或密码后重试 |

## 2. 任务管理模块 (TaskController)

### 2.1 获取任务列表
- **接口描述**：获取系统中所有的任务列表。
- **请求路径**：`/tasks`
- **请求方法**：`GET`
- **请求头**：`Authorization: Bearer {token}`

#### 请求参数
无

#### 返回参数
| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| code | Integer | 状态码（200为成功） |
| message | String | 提示信息 |
| data | Array | 任务对象数组（见下方 Task 对象说明） |

**Task 对象结构：**
| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | Long | 任务唯一标识 |
| title | String | 任务标题 |
| status | Integer | 任务状态（0: 待办, 1: 已完成） |

#### 错误码定义
| 错误码 | 说明 | 处理建议 |
| :--- | :--- | :--- |
| 401 | 未登录或 Token 过期 | 请重新登录获取 Token |

### 2.2 创建新任务
- **接口描述**：创建一个新的任务。
- **请求路径**：`/tasks`
- **请求方法**：`POST`
- **请求头**：`Content-Type: application/json`, `Authorization: Bearer {token}`

#### 请求参数
| 参数名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| title | String | 是 | 任务标题 |

#### 返回参数
| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| code | Integer | 状态码（200为成功） |
| message | String | 提示信息 |
| data | Object | 创建成功的 Task 对象（包含生成的 id, title, status） |

#### 错误码定义
| 错误码 | 说明 | 处理建议 |
| :--- | :--- | :--- |
| 400 | 参数校验失败（如 title 为空） | 请检查请求参数 |
