# 项目 Demo 展示脚本

## 1. 演示环境与预置数据
- **环境**：本地启动 Spring Boot 服务，默认端口 8080。
- **预置数据**：在 `application.yml` 中配置 H2 内存数据库（或 MySQL），启动时自动执行 `schema.sql` 和 `data.sql`，预置测试用户（admin / 123456）和 3 条默认任务数据。

## 2. 正常交易链路演示
- **登录流程**：访问 `/login` 页面，输入预置的账号 `admin` 和密码 `123456`，点击登录。系统验证通过，跳转至任务列表页，并成功下发 Token。
- **任务查询**：进入任务列表页，系统通过 `GET /tasks` 接口拉取预置的 3 条任务数据，页面正常渲染展示。
- **新建任务**：点击“添加任务”，输入任务标题“DevOps 验收测试”，提交表单。系统通过 `POST /tasks` 接口成功创建任务，页面刷新显示 4 条任务。

## 3. 极端边界报错演示
- **空参数校验**：在新建任务时，标题栏留空直接点击提交。系统前端触发校验或后端返回 `400 Bad Request`，提示“任务标题不能为空”。
- **超长文本输入**：在任务标题中输入超过 255 个字符，演示系统截断或报错处理。
- **未授权访问**：清除浏览器的 Cookie，直接访问 `/tasks` 接口，系统拦截器生效，重定向回登录页或返回 `401 Unauthorized`。

## 4. 异步处理表现
- **模拟异步**：在新建任务成功后，系统后台通过 `@Async` 注解异步打印日志“任务创建成功通知已发送”，主流程不等待通知发送，直接返回成功响应，页面无卡顿感，体现异步处理对用户体验的提升。
